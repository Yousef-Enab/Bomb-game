# القنبلة — لعبة جماعية عبر الإنترنت (نسخة الحلبة الصحراوية)

الخادم هو المرجع الوحيد للوقت والقلوب والأدوار. التفاصيل الكاملة (الملفات، صيغة الأسئلة، الأصول، القواعد، الاختبارات): **CHANGES.md**.

## التشغيل
يحتاج Node.js 18+ (بلا اعتماديات ولا `npm install`).
```bash
npm start      # http://localhost:3000
npm test       # اختبارات المنطق + تكامل بعدة عملاء + الأصول + التخطيط
```
اختبار المتصفح الحقيقي (اختياري، يحتاج Python وPlaywright): `npm run e2e`

## النشر (Render أو أي استضافة Node)
Start Command: `node server.js` · Build Command: فارغ. لا مفاتيح API. ارفع **كل** ملفات المشروع (خصوصاً كل ما في `public/`)، فالخادم يستورد `public/config.js`.

## إضافة أسئلة
افتح `questions.js` — الصيغة موثّقة في أعلاه وفي CHANGES.md (إجابة واحدة `Q(...)`، أو عدة إجابات `M(...)`).

## استبدال الأصول
كل المسارات والتوقيتات في مكان واحد: `public/config.js` (والأبعاد/مدد الإطارات في `public/sprites.js` المولَّد). لتغيير الرامي/اللاعبين: ضع الـGIF الجديدة في `tools/source/` ثم `npm run sprites`.
